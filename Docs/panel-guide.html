What every control in the panel does

The module panel has four sections, and you work down them in order: Dataset picks the case, Display sets up what you see, Lesions lists what there is to check, Editing changes it. Each control below is named exactly as it appears on screen.

The panel, top to bottom

  1. Datasetwhich case
  2. Displaywhat you see
  3. Lesionswhat to check

Dataset

Points the tool at a batch of cases and decides which mask you are correcting. Nothing here writes to disk except Delete review.

Batch directorypath + Browse & load…

The folder that contains the case folders — one level deep, so point at batch_01, not at its parent and not at a single case.

The dropdown remembers the last ten batch directories you opened.

Case< Prev · dropdown · Next > · 1 / 50

Moves between cases. A ✓ after a case name means a review has already been saved for it. The counter on the right is your position in the filtered list.

Skip already reviewed casescheckbox

Hides every case that already has a saved review, so Next walks only the work that is left.

Mask sourcedropdown

Which mask of this case you are reviewing — typically seg, or pred_seg where there is no ground truth yet. If a review was saved earlier it is offered here too, so you can pick up where you left off.

Delete reviewbutton

Removes this case's <case>_reviewed_seg.nii.gz from disk and reopens the case from its original mask. Greyed out when there is no saved review.

This is the one control undo cannot reach. It deletes a file. It names the file and asks first, and any unsaved edits in the editor go with it.

The file listread-only

Under the controls, the case's files with their short keys — t1c, pred_seg, seg. The dot marks the one currently loaded. The greyed path below is the case folder.

Display

Everything here changes only what reaches your eyes. No control in this section can alter a voxel.

Imagedropdown

Which sequence sits underneath the mask. Also the image the intensity-based tools read, so switching it changes what Sphere threshold measures.

Compare with · Blenddropdown + slider

A second sequence faded over the first — t1c over flair, say. Both rows stay hidden for a case with only one sequence, which is most of them.

Contrastwindow / level

Brightness and contrast of the image. Auto follows the volume; Manual lets you drag the range or type W and L. The … button holds the modality presets.

Layoutdropdown

Four-Up, 1×1 Red (axial), 1×1 Yellow (sagittal), 1×1 Green (coronal), 2×2 slices, or Conventional. One slice filling the window is usually the fastest way to paint.

Slices: align to the image gridcheckbox · on by default

Rotates the slice views onto the mask's own voxel axes.

In this data the mask sits a median 8.3° off the anatomical axes, so the ordinary axial/coronal/sagittal planes cut the voxel grid diagonally — and a stroke you draw as a clean disc is committed as a stair-stepped one. Untick it when you want true anatomical orientation to judge anatomy.

Mask: show + slidercheckbox + opacity

Hides the mask or fades it, so you can see the underlying tissue you are deciding about. On the keyboard: s hides and shows, a and d step the fill 10% either way.

Reset field of viewbutton

Re-centres and re-fits every slice view on the volume. The same thing r does with the pointer over a view.

Lesions

Every connected component of the current mask, recomputed as you edit. This list is your worklist: the case is not finished until each row is ticked.

New lesiontoggle button

Arms the brush over empty mask. Paint anywhere nothing is labelled and the stroke becomes its own row once the list refreshes. It uses whatever Active label is set to. Esc cancels.

#column

A rank by size — not a name. Numbers are handed out afresh on every recount, so a lesion's # changes when another lesion is painted, deleted, or grows past it. Your Done ticks are tracked by position in the volume, not by number, so they survive the renumbering.

Voxels · Volume (mm3)columns

Size of the component, in voxels and in physical volume. Click either heading to sort; the list opens sorted by size, largest first.

Donecheckbox column

Your record that you have looked at this lesion and are happy with it. Save & next case stays disabled until every row is ticked.

🗑per-row button

Deletes that whole lesion — every one of its voxels, from every label. It asks first, naming the voxel count, and it is undoable with Ctrl+Z. Nothing is written to disk until you save.

Selecting a rowbehaviour

Jumps every slice view to that lesion's centre and briefly flashes it, so you can tell which of several nearby components you have. The centre is snapped to a voxel that is genuinely inside the lesion, so it never lands in a hole.

Selecting a row is also what unlocks the brush — see Editing.

The summary lineread-only

3 lesions | 4059 voxels | 4059.0 mm3 | 0/3 done — the whole case at a glance. The done count turns green when the case is ready to save.

Editing

Two questions before any tool: which label goes down, and what it is allowed to paint over. Then the tool itself.

Undo · Redo · Resetbuttons

One press is one operation — a whole brush stroke, a lesion delete, a threshold apply. Reset is different: it reloads the mask from disk and discards everything since your last save.

Active labeldropdown

What the brush lays down:

  • 1 - Necrosis and Cavity
  • 2 - Enhancing Tumor
  • 3 - Edema
  • Background (erase) — painting background is erasing, so choosing it arms the Erase tool.

It follows the lesion you select, and picking a tool with the digit keys sets it back to that lesion's label.

Paint overdropdown

Which voxels the brush may change:

  • All labels — overwrite anything.
  • Background only — never touch a voxel that already has a label, so you can fill a gap without eating its neighbour.
  • Only 1 - … / Only 2 - … / Only 3 - … — only that label may be painted over.

It applies to all three tools, threshold included.

None · Paint · Erase · Sphere thresholdtool row

The tools, on 1 2 3. Each one's settings appear directly underneath.

Painting applies as the cursor moves rather than waiting for the mouse button, so what you see under the brush is what is committed.

The brush is locked until a lesion is selected, or until New lesion is armed. That is deliberate: it stops a stray click landing somewhere nobody is reviewing.

Sphere thresholdtool

Click the centre of a lesion and drag outward. A circle follows the pointer; release, and every voxel inside the sphere whose intensity is close to the one you clicked is added — in one undo step.

  • Tolerance — how far an intensity may deviate from the clicked voxel, as a percentage of it.
  • Include — similar to the seed, or additionally everything brighter / darker than it.
  • Only voxels connected to the seed — leaves unrelated bright spots inside the sphere alone.
  • 2D: this slice only — a disc on the slice you drew on instead of a ball through the ones you are not looking at. Use it when a lesion is only convincing on one slice.
Save & next casebutton

Writes <case>_reviewed_seg.nii.gz next to the case and opens the next one. Ctrl+S saves without moving on.

Disabled until every lesion is ticked Done — hover it and the tooltip says how many are left. The original mask is never modified; the review is always a new file.

The loop, and the keys

What a case actually looks like from open to save.

  1. Open the batch once — Browse & load…, then tick Skip already reviewed cases.
  2. Take the first lesion from the list. The views jump to it.
  3. Look before you touch. s hides the mask, a and d fade it — decide whether the boundary is right against the image, not against the overlay.
  4. Correct it if it needs it: paint, erase, or pull a threshold sphere. Ctrl+Z takes back whole operations.
  5. Tick it Done and move to the next row.
  6. Save & next case once every row is ticked.

GTReview is a scripted 3D Slicer extension. It reads your ground-truth masks and writes its output as a separate _reviewed_seg.nii.gz beside each case — the files you point it at are never modified.

Labels: 1 Necrosis and Cavity · 2 Enhancing Tumor · 3 Edema. No other label exists, and nothing in the panel can add one.
